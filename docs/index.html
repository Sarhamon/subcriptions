발표 C
문제 해결 과정

환율 API 연동 — 2가지 핵심 오류

1
Frankfurter — KRW 미지원
외부 API네트워크
content-type: text/html;charset=UTF-8 → JSON 아닌 HTML 에러 페이지 반환

원인: Frankfurter = ECB 데이터 소스. KRW는 ECB 미포함
해결: open.er-api.com으로 교체 (KRW 지원)

2
역직렬화 실패 → Map 방식으로 전환
런타임 오류빈 주입

private record: Jackson이 canonical constructor 접근 불가
RestClient.Builder: Spring Boot 4에서 자동 빈 등록 안 됨

→ Map<String, Object> + ParameterizedTypeReference로
두 문제를 한 번에 해결

Map<String, Object> body = restClient.get().uri(API_URL) .retrieve().body(RESPONSE_TYPE); BigDecimal krw = new BigDecimal(rates.get("KRW").toString());

💡 Jackson 직접 import 불필요, 커스텀 record 불필요, 빈 주입 불필요 — 구조 단순화로 의존 문제가 모두 사라짐

발표 D
SubscriptionView DTO

뷰 전용 불변 객체

Mustache는 로직 작성 불가.
모든 계산을 생성자에서 완료하고
템플릿은 순수 출력만 담당.

핵심 필드
  • daysText — "오늘" | "N일 후"
  • colorClass — c1~c4 (id % 4 스트라이프)
  • emoji — 서비스명 기반 자동 배정
  • monthlyKrw — 연간이면 ÷ 12 환산
  • dueSoon / dueSoon7 — 3일 · 7일 이내
  • displayPrice — 외화 시 원화 병기
생성자에서 모든 계산 완료
this.daysUntilRenewal = ChronoUnit.DAYS.between(now, nextRenewalDate); this.dueSoon = daysUntilRenewal <= 3; this.dueSoon7 = daysUntilRenewal <= 7; this.daysText = daysUntilRenewal == 0 ? "오늘" : daysUntilRenewal + "일 후"; // 카드 색상 스트라이프 this.colorClass = classes[(int)((id-1) % 4)]; // 연간 → 월 환산 this.monthlyKrw = billingCycle == YEARLY ? Math.round(krw / 12f) : krw;
