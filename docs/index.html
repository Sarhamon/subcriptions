발생한 문제

환율 API 연동 오류

1
Jackson private record 역직렬화 실패
런타임 오류
Cannot construct instance of `ExchangeRateService$FrankfurterResponse` (no Creators... exist)

원인: private record는 Jackson이 canonical constructor에 접근 불가
해결: private 제거 → package-private

2
Frankfurter API — KRW 미지원
외부 API네트워크
content type [text/html;charset=UTF-8] → HTML 에러 페이지 반환

원인: Frankfurter = ECB 데이터. KRW는 ECB 미포함
해결: open.er-api.com으로 교체 (KRW 지원)

💡 핫스팟으로 바꿔도 동일 오류 → 학교 프록시가 아닌 API 자체의 KRW 미지원이 근본 원인임을 확인

Jackson ObjectMapper import 컴파일 오류
컴파일 오류
package com.fasterxml.jackson.databind does not exist

원인: Jackson은 transitive dep — 런타임엔 존재, 컴파일 classpath 미노출
해결: 직접 import 방식 포기 → Spring 내부 Jackson 활용

발생한 문제

Deprecated API & 빈 주입 오류

5
Spring Framework 7.0 Deprecated API 경고
Deprecated

MappingJackson2HttpMessageConverter, messageConverters(Consumer) — Spring 7에서 제거 예정
→ 커스텀 컨버터 설정 전체 제거, RestClient.create()로 교체

6
RestClient.Builder 빈 미등록 → 앱 기동 실패
런타임 오류
No qualifying bean of type 'org.springframework.web.client.RestClient$Builder' available

Spring Boot 4 환경에서 RestClient.Builder 자동 빈 등록 안 됨 → Map<String, Object> 방식으로 전환하여 빈 주입 자체를 불필요하게 구조 변경

문제 해결 — 최종

Map<String, Object> 역직렬화

✓커스텀 record 불필요
✓unknown property 문제 없음
✓Jackson 직접 import 불필요
✓빈 주입 불필요 — RestClient.create()
✓toString() 경유 BigDecimal 변환으로 부동소수점 정밀도 유지

ParameterizedTypeReference는
org.springframework.core 소속 —
Jackson 의존 없이 사용 가능

변경 전 — 커스텀 record
record ExchangeRateResponse( Map<String, BigDecimal> rates) {} restClient.get().uri(API_URL) .retrieve() .body(ExchangeRateResponse.class);
변경 후 — Map<String, Object>
private static final ParameterizedTypeReference<Map<String, Object>> RESPONSE_TYPE = new ParameterizedTypeReference<>(){}; Map<String, Object> body = restClient.get() .uri(API_URL) .header("Accept","application/json") .retrieve().body(RESPONSE_TYPE); Map<String, Object> rates = (Map<String, Object>) body.get("rates"); BigDecimal krw = new BigDecimal(rates.get("KRW").toString());
